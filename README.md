# EventHub

EventHub ist unser Studienprojekt im Modul Web-Anwendungen.
Wir entwickeln eine Website, auf der Nutzer Veranstaltungen
entdecken und sich über Events informieren können.

## Projektziel

Die Anwendung soll eine Übersicht verschiedener Veranstaltungen
bieten und später die Buchung von Tickets ermöglichen.

## Verwendete Technologien

- HTML für den Aufbau der Seiten
- CSS für Gestaltung und responsive Darstellung
- JavaScript für interaktive Funktionen

## Aktueller Stand

- 2. Teil des Projekts : HTML-Prototyp und CSS- Dateien erstellen.


## Projektstruktur

- public/index.html: Startseite
- public/event.html: Eventdetailseite
- public/buchung.html: Buchungsseite
- public/kontakt.html: Kontaktseite
- public/impressum.html: Impressum
- public/agb.html: Allgemeine Geschäftsbedingungen
- public/datenschutz.html: Datenschutzhinweise
- public/css/style.css: Gemeinsames Stylesheet
- public/images/: Verwendete Bilder
- public/js/: JavaScript-Dateien

## Starten

1. Das Repository herunterladen oder klonen.
2. Den Projektordner in Visual Studio Code öffnen.
3. Die Datei public/index.html im Browser öffnen.

Für die bisherige Startseite sind keine zusätzlichen
Installationen notwendig.
